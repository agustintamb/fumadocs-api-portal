## Carpetas principales

```
apis/                     Especificaciones OpenAPI (YAML)
content/
  docs/                   Páginas MDX de la documentación
  api-store/              meta.json de cada API y versión
e2e/                      Tests end-to-end (Playwright)
public/                   Archivos estáticos
src/
  app/                    Rutas de Next.js
  components/             Componentes compartidos
  data/                   Datos de ejemplo
  i18n/                   Textos propios en español
  lib/                    Configuración de Fumadocs y OpenAPI
  utils/                  Funciones puras con tests
```

## Rutas

| Carpeta                     | Contenido                                                     |
| --------------------------- | ------------------------------------------------------------- |
| `src/app/(home)/`           | Inicio, Dashboard y API Store, con el layout de Inicio        |
| `src/app/(docs)/[...slug]/` | Documentación y referencia de las APIs, con el layout de Docs |
| `src/app/api/proxy/`        | Proxy que usa el playground para evitar CORS                  |
| `src/app/api/search/`       | Endpoint de búsqueda                                          |

Cada vista de `src/app/(home)/` tiene su `page.tsx`, un componente de página, una carpeta `_components/` y, si tiene lógica, un hook (`useX.ts`).

## Archivos clave

| Archivo                      | Función                                                       |
| ---------------------------- | ------------------------------------------------------------- |
| `src/lib/source.ts`          | Une el contenido MDX con las páginas generadas desde los YAML |
| `src/lib/openapi.ts`         | Instancias de OpenAPI, una por especificación                 |
| `src/lib/layout.shared.tsx`  | Links del navbar                                              |
| `src/lib/translations.ts`    | Traducciones de Fumadocs y del playground                     |
| `src/components/mdx.tsx`     | Componentes disponibles en los archivos MDX                   |
| `src/components/SiteHeader/` | Header común a todas las secciones                            |
| `src/app/global.css`         | Tema, colores y estilos propios                               |
| `content/docs/meta.json`     | Orden y separadores de la barra lateral de Docs               |

## Comandos

```bash
npm run dev        # servidor de desarrollo
npm run build      # build de producción
npm test           # tests unitarios
npm run test:e2e   # tests end-to-end
```
