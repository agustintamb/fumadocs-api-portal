## MDX o página de React

<Callout title="Dos enfoques para el mismo contenido">
  El API Store (`src/app/(home)/api-store/`) es una página de React con búsqueda y
  filtros. Esta versión es contenido estático en MDX. Ambos enfoques son válidos.
</Callout>

### Cuándo usar MDX

- Contenido de documentación con formato (encabezados, tablas, bloques de código).
- Páginas que pueden editar personas sin conocimientos de React.
- Contenido estático o casi estático.

### Cuándo usar una página de React

- Páginas con estado, como búsquedas o filtros.
- Paneles, formularios o cualquier interfaz interactiva.
- Páginas que obtienen datos dinámicamente.

<Callout type="idea" title="Se pueden combinar">
  Las páginas de React pueden mostrar contenido MDX, y las páginas MDX pueden incluir
  componentes de React registrados en `src/components/mdx.tsx`.
</Callout>
